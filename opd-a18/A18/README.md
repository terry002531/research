# A18

A18（2026-11-03 定名，原名 A17·es）= A17 + 门控支证据挑缩放。

接手的人先读 `交接文档.md`：项目背景、思路、A11 到 A18 的路线、怎么跑、规矩和下一步。

- **A17**：A16A + 结构解法 SS + 融合验证集按 C 缩放，见 `../A17`。
- **证据挑缩放**（`code/a16_ss.py` 里的 `escale`）：门控支的读数先按 C 估的峰值缩放，再在 0.45–1.3 倍之间取 11 个倍数，逐条挑 GaussX 边缘似然（加上换元雅可比 n log c）最大的那个。门控支在挑出的读数上计算，输出再除回这个倍数。网格是否只在非测试诊断集上定：无法核实，看不到选网格的过程（`diag/scale_ev.out` 只有选定后的结果）。诊断集 VSEED+21 的 CIE LED 族和测试集是同样 9 条谱。

## 运行

在 `06_重建算法/算法对照` 目录下（驱动脚本和其他算法共用，留在原处；`code/` 里是 2026-11-03 的快照）：

```bash
py -I -X utf8 a15_three.py --third cnet0 --no-b --a16a 32 --a16a-ss --a16a-vscale --a16a-escale --test-seed 6161
```

输出到 `A18/results/a18_seed<种子>/`。

## 文件夹

- `results/a18_seed6161/`：测试结果（这一份是改名前跑的，日志里算法名还写着 A17·es，数字相同）。
- `results/a18_seed4242/`：开发种子 4242（不作论文数字）。主运行 14:43–15:13；指标段 15:22–16:51 用 cholesky 兜底版单独重跑，兜底累计 133411 个元素，各档分布不知道。见其中的 `说明.md`。
- `results/latency_R1/`：单条延迟计时的输出目录（脚本已写好，还没跑）。
- `HANDOFF_A18-R1.md`：A18-R1 两轮改动清单。
- `ablation/`：同种子同读数的对照，有 A16、A16A、A16A·ss、A16A·vs、A17。
- `diag/`：缩放诊断。`fuse_diag2` 是几种不用真值的幅度估计，`scale_ev` 是证据挑缩放。
- `code/`：`a16_ss.py`，以及 `a15_three.py` 快照。

## 结果（测试种子 6161，真实模式）

| | A16 | A17 | A18 |
|---|---|---|---|
| 26 族几何平均形状误差 | 0.0682 | 0.0647 | 0.0628 |
| 窄线峰位误差中位 | 0.272 nm | 0.210 nm | 0.233 nm |
| 门控支推理时间 | — | 15 ms/条 | 92 ms/条 |

推理时间是批量平摊：整次运行全部 decode 的时间除以读数条数（含验证集和理想模式），没排除并发负载，不是单条延迟。单条延迟见 `算法对照/a18_latency.py`（还没跑）。测试集每族 40 条谱，CIE LED 族只有 9 条。

- A18 比 A17 好 2.9 %：逐族好 14 族、差 9 族。
- A18 比 A16 好 7.9 %：逐族好 22 族、差 2 族。
