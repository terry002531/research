## 1. 结论（更新后的排序）

| 排序 | 方向 | 改动原因 |
|---|---|---|
| **主线** | **B + C：用单器件测量预测 SWIR OPD 的成像性能（时域噪声）** | 现有仪器基本够用，只需补 InGaAs 参比和示波器；不依赖读出平台；风险最低 |
| **扩展 / 第二篇** | **D：共享有源层的像素串扰（空间维度）** | 锁相 + 调制激光点扫描正好对口；**不需要读出平台**，只要同事做几组测试电极 |
| 可选 | A：考虑器件物理的单像素成像 | 需要另外买 DMD，从零搭光路，风险最大。先做纯仿真，不花钱 |

**核心故事**：读出平台还没有，那就先回答"这些 SWIR OPD 放进成像器以后会怎样"。
- 时域：噪声谱 → 积分型读出下的 SNR 和动态范围（B）；暗电流和噪声的物理来源（C）
- 空域：像素串扰和 MTF（D）

如果 D 进展顺利，可以和 B/C 合成一篇，完整回答"从单器件测量预测成像器的时域和空域性能"，冲 LPR / ACS Photonics。如果 D 慢了，B/C 单独成文，投 AOM / ACS Photonics。

## 2. 仪器能做什么，局限在哪

| 仪器 | 在这个课题里的用途 | 局限 / 注意事项 |
|---|---|---|
| **Keithley 6430** | 暗 J–V（fA 级）、暗电流随时间的漂移、偏压应力测试 | 低电流档很慢，要设够积分时间和延迟；**必须**用屏蔽盒和低噪声三同轴线缆 |
| **SR860** | 噪声谱密度：固定参考频率，读 ENBW 内的噪声，然后扫频；频率响应 / −3 dB 带宽（配调制光源）；EQE 的锁相读出；D 方向的串扰点扫描 | 电流输入的噪声本底：10⁶ 档约 100 fA/√Hz，10⁸ 档约 10 fA/√Hz（以手册为准）。**最好的器件散粒噪声只有 10–30 fA/√Hz**，可能接近这个本底。一定要先测"不接器件"时的本底，必要时用外置低噪声 TIA，或者做更大面积的器件 |
| **34461A** | 接在 TIA 输出后面录时域电压，大约 ≤1 kSa/s，做 FFT 可以得到 <500 Hz 的噪声谱，正好覆盖 1/f 区；这些数据也是"虚拟积分像素"（见 §3）的原始输入 | 采样率低，测不了 µs 级瞬态 |
| **TIA / 电流前放** | 所有时域和噪声测量的前端 | 它的输入噪声和带宽决定能测多低；要记录增益档和带宽 |
| **函数发生器 + SWIR 激光/LED** | 调制光：频率响应、瞬态、LDR、串扰扫描 | LED 驱动的调制带宽要确认 |
| **疑似椭偏仪** | 测膜厚 | **手动椭偏仪多数是单波长（HeNe 633 nm）**，一般只能给出厚度和 633 nm 处的 n，**给不出 1000–1300 nm 的 n、k 谱**。n、k 需要找合作方做光谱椭偏，或者用文献数据 |
| **SPA400（疑似 SII/精工 扫描探针显微镜）** | 形貌、粗糙度、台阶法测厚度；如果有导电 AFM 模式，还能找漏电点和针孔（这对 C 很有价值） | 请确认有哪些模式 |

## 3. 主线（B + C）的具体方案

### 3.1 要回答的问题

1. 1000–1300 nm OPD 的噪声由什么构成（散粒、热、1/f、产生-复合）？1/f 拐点频率随偏压和暗电流怎样变化？
2. 放进**积分型像素**（积分时间 1–100 ms，CDS 采样）后，决定 SNR 和动态范围的是哪一项？按散粒噪声 D\*、实测 D\* 和成像 SNR 排序，三种结果是否一致？
3. 暗电流主要来自哪里：陷阱产生、接触注入，还是分流/针孔？离物理极限还有多远？

### 3.2 "虚拟积分像素"：不依赖读出平台的验证方法

1. 用 TIA 加 34461A（后面也可以用示波器）录下**暗电流的长时间序列** i(t)。
2. 在电脑上模拟一个像素：
   - 按积分时间 T 对 i(t) 积分，得到电荷 Q；
   - 做 CDS，即相邻两帧相减或复位后采样；
   - 加入 kTC 噪声和读出噪声，按一个典型节点电容 C 取值。
3. 统计 Q 的方差随 T 的变化，得到**输入等效噪声电子数 σₑ(T)**。
4. 和"噪声谱乘以积分/CDS 传递函数再积分"的解析预测比对。**两条路径一致，就证明模型可信。**
5. 条件允许的话，再在面包板上搭一个**真实的 CTIA**（低漏电运放 + 反馈电容 + 复位开关），实测一组 σₑ(T)，作为最终验证。
6. 输出 [EMVA 1288](https://www.emva.org/wp-content/uploads/EMVA1288Linear_4.0Release.pdf) 风格的指标：SNR 随光子通量的曲线、动态范围、NEI（噪声等效辐照度）、暗电流占满阱的时间。

### 3.3 室温条件下研究暗电流机理（C）

不能变温，就用下面几种替代手段组合：
- **厚度系列**：同一共混体系做 3–4 个厚度。体产生电流随厚度增加，界面注入电流和厚度关系弱。
- **面积系列**：同一片上做不同面积的器件。电流按面积缩放说明是体过程或界面过程；按周长缩放说明是边缘漏电。
- **偏压依赖**：看是否符合 Poole-Frenkel / 场增强产生，还是更像注入（Schottky）。
- **界面层对照**：换或去掉阻挡层，由同事提供。
- **自己写的一维漂移-扩散模型**：统一拟合上面这些数据，把暗电流分解成陷阱产生、注入和分流三部分。
- **AFM（如果有导电模式）**：看针孔和局部漏电点。
- **（可选，预算内）买一个帕尔贴温控台**，用来提取激活能。温度范围大约室温到 80 °C 就够（升温方向不会结露）；如果要降温，需要加氮气或真空腔。

### 3.4 需要同事提供的器件

| 组别 | 内容 | 作用 |
|---|---|---|
| 1 | 同一体系，3–4 个有源层厚度 | 厚度系列，区分体产生和界面注入 |
| 2 | 同一体系，有/无阻挡层（或换一种界面层） | 看界面对暗电流和 1/f 噪声的影响 |
| 3 | 2–3 个不同的 SWIR 体系（截止波长 1100–1300 nm） | 横向对比；检验"D\* 排名 ≠ 成像 SNR 排名" |
| 4 | 每个样品上都有不同面积的器件 | 面积/周长缩放 |

每种条件至少 3–4 个器件，才能给出误差棒。

## 4. 扩展方向 D（像素串扰）的简化方案

- **测试结构**：同一片衬底上，底电极做成 2–5 条平行条带，间距 10 / 20 / 50 / 100 µm，有源层和顶电极都不图形化。
- **测量**：1064 或 1310 nm 激光用函数发生器调制，聚焦成约 10 µm 的光斑，沿垂直于电极的方向扫描。SR860 分别读"被照电极"和"相邻电极"的光电流，得到线扩散函数，再换算成 MTF。锁相可以把很小的串扰电流从暗电流和噪声里提出来，这是它的优势。
- **变量**：有源层厚度（沿用主线的厚度系列）、界面层（PEDOT:PSS、ZnO 等横向电导不同）、偏压。
- **模型**：2D 漂移-扩散模型，或者简化成"横向电阻网络 + 载流子扩散"。
- **输出**：SWIR 需要厚膜来提高 EQE，但厚膜会降低 MTF。给出 EQE、MTF 和像素间距之间的权衡图谱。

## 5. A（单像素成像）先做零成本的准备

- 现在可以先写仿真：用前向模型 y = h(t, I) ⊛ (P·x) + n，其中 h 暂时用文献里的多指数响应，得到重建质量随"图案刷新率/f₋₃dB"的变化曲线。
- 等主线测到真实器件的瞬态响应后，把 h 换成实测值，看效果是否值得搭实验。
- 硬件方面，可见光版的 DMD 在 1000–1300 nm 通常也能用，只是效率会下降，需要实测。这个判断依据要在搭之前核实。
