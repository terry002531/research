## 3. 课题之间的关系

```
            复用噪声测量平台和 1064 nm 器件数据
      ┌──────────────────────────────┬───────────────────────┐
      ▼                              ▼                       ▼
 A 设计研究（仿真）          C 散粒近似定量研究（实验）   B 偏置锁定（实验）
      │                              │                       │
      │ 给出"片上 OPD 做监控"的结论    │ 和综述同主题，            │ 用实验验证 A 的应用结论
      │ 以及理论 NEP 要求              │ 在综述之后发，引用综述     │（10 月底前借到设备就并进 A）
      └──────────────◄──────────────────────────────────────────┘
      A 走不通时，C 提前开始（C 是 A 的后备）
```

- **噪声测量平台**在 A 里第一次搭好（屏蔽、TIA、SR860 扫频、34461A 录低频），C 和 B 直接复用。
- **B 验证 A**：A 从理论上给出"偏置锁定需要多小的 NEP"，B 用实验测出来。
- **C 是 A 的后备**：切换条件见 C 提案 §9。
