## 1. 题目

**中文**：以有机光电探测器作为铌酸锂调制器偏置锁定的监控探测器：锁定精度与探测器噪声的定量关系

**英文（暂定）**：*Organic photodetectors as monitor photodiodes for bias locking of lithium niobate modulators: linking locking accuracy to detector noise*

---

## 2. 背景与动机

1. **铌酸锂调制器的偏置点会漂移**，TFLN 调制器的直流漂移问题尤其明显。实际系统都需要偏置控制：用监控探测器测输出功率，再反馈调节偏置电压（[相关讨论](https://www.researchgate.net/publication/364217663_Thin-film_lithium-niobate_modulator_with_a_combined_passive_bias_and_thermo-optic_bias)）。
2. 以后要把监控探测器做到 TFLN 芯片上，就需要可以异质集成的探测器。课题 A 从设计上论证了 OPD 是 1 µm 波段的候选方案。**但还没有实验回答：监控探测器到底要多好？OPD 够不够？**
3. OPD 有几个公认的短板：**1/f 噪声大、响应度和暗电流会漂移、响应慢**。
4. **本课题的核心看点**：常用的"抖动 + 锁相"偏置控制，锁定点由谐波信号的**过零点**决定。从原理上看，它**对探测器响应度的比例变化和直流偏移不敏感**。如果实验证实了这一点，OPD 的稳定性短板在这个应用里就影响不大，这是一个对 OPD 有利、又不显然的结论。

---

## 3. 研究问题与假设

| # | 问题 | 假设 |
|---|---|---|
| Q1 | 锁定精度和监控探测器在抖动频率处的信噪比是什么关系？ | 锁定相位误差 ≈ 噪声 / 误差信号斜率，因此 ∝ NEP(f_d) / P_mon。可以从实测噪声谱**预测**锁定精度 |
| Q2 | 抖动频率 f_d 怎么选？ | 存在最优值：f_d 低于 OPD 的 1/f 拐点时噪声大，高于 f₋₃dB 时信号小，所以最优点在两者之间 |
| Q3 | OPD 响应度衰减或暗电流漂移时，锁定点会不会跟着偏？ | **不会（或很小）**：过零点和响应度的比例因子、直流偏移无关 |
| Q4 | 同样条件下，OPD 和商用 Si/InGaAs 光电二极管差多少？ | 监控信噪比相同时，两者的锁定精度相同。差别只来自 NEP，而 NEP 的差距可以用增加分光比来补偿 |

## 4. 实验方案

### 4.1 光路和电路
```
1064 nm 光纤激光 → 保偏光纤 → 铌酸锂强度调制器（商用体材料器件） → 保偏分束耦合器（如 90:10）
                                     ↑ 偏置 = 直流 + 小幅正弦抖动          │90%             │10%
                                     │                                   ▼                 ▼
               函数发生器（直流偏移 + 正弦）或 6430 + 加法电路   环外参考探测器        可调衰减 → 准直器 → OPD → TIA → SR860
                                     ↑                            （测真实锁定误差）                                │
                                     └─────────── 电脑上的 PI 反馈（Python 读 SR860、改偏置）←─────────────────────┘
```

### 4.2 原理
- 在偏置上加一个小的正弦抖动（频率 f_d），用 SR860 解调监控信号的谐波：
  - **一次谐波** ∝ 传输曲线的斜率，过零点就是最高点或最低点；
  - **二次谐波** ∝ 曲率，过零点就是正交点。
- 电脑用 Python 读锁相输出，做 PI 反馈，调节直流偏置。回路带宽约 1–10 Hz，足够跟踪慢漂移。
- **环外参考探测器**独立测量真实的输出功率，用它算出实际锁定误差，避免"自己评价自己"。

### 4.3 测量内容

| # | 测量 | 回答 |
|---|---|---|
| 1 | 扫偏置测传输曲线，定出 V_π；测 OPD 在 1064 nm 的噪声谱和 f₋₃dB（**沿用课题 A 的噪声测量平台**） | 基础参数 |
| 2 | 锁定与不锁定时的长时间输出对比（数小时）；人为施加扰动（改变调制器温度、给偏置加阶跃），测恢复过程 | 功能演示 |
| 3 | 用可调衰减器扫进入 OPD 的监控功率，测锁定误差随功率的变化，并和由噪声谱算出的预测曲线对比 | Q1 |
| 4 | 在 10 Hz 到 f₋₃dB 之间扫抖动频率，测锁定误差，并叠上 OPD 的噪声谱 | Q2 |
| 5 | 锁定过程中人为改变 OPD 响应度（例如降低 OPD 的偏压，或换一个性能已衰减的器件），再加一个背景光作为直流偏移，看锁定点是否移动 | Q3 |
| 6 | 用商用 Si 或 InGaAs 光电二极管替换 OPD，重复第 3 和第 5 项 | Q4 |

## 6. 预期的图

1. 实验装置；一次、二次谐波误差信号随偏置的变化（原理验证）
2. 锁定与不锁定的长期对比；扰动后的恢复过程

4. 锁定误差随抖动频率的变化，叠上 OPD 的噪声谱
5. **鲁棒性**：响应度下降、加入直流偏移时锁定点不动（对 OPD 有利的关键结论）
6. OPD 与商用光电二极管的对比；把"锁定所需的 NEP"和课题 A 预测的片上 OPD NEP 画在一起

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 借不到调制器，预算也不够 | 本课题暂缓；A 和 C 不受影响 |
| 锁定误差主要由激光功率噪声、偏振漂移或温度决定，而不是探测器 | 用环外参考探测器做归一化；使用保偏光纤；在报告中把各项误差来源分开 |
| 调制器漂移太慢，几个小时里看不出区别 | 人为施加温度或电压扰动，来测试锁定能力 |
| OPD 在连续光照下性能衰减 | 这恰好是 Q3 的测试内容，把它当作数据记录下来 |
