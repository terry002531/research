# Luong 2024 标定：图与讲解

> 文献：Hoang Mai Luong 等，*Highly Sensitive Resonance-Enhanced Organic Photodetectors for Shortwave Infrared Sensing*，ACS Energy Lett. 2024（核验表 S8）。数据全部取自作者稿 arXiv 2309.07370（55 页版本，含 SI）。
> 器件：glass/ITO(130)/ZnO(40)/PTB7-Th:COTIC-4F/MoOx(7)/Ag(100)，面积 4.7 mm²，目标波长 1100 nm。
> 脚本：`luong2024_fig.py`，输出 `luong2024_fig6c.png`（四联图）与 `luong2024_dV.png`（d–V 可行域）。

## 3 讲解

### 图 (a)：为什么厚度要“踩点”

活性层在 1100 nm 处只是弱吸收的尾部，单程只能吸收约 12%。把它放进两面镜子之间以后，只有满足 d = (m − φ/2π)·λ/(2n) 的厚度才发生相长干涉，吸收在共振处被放大到 60–80%，偏离共振就跌到 2–8%。

所以吸收下限在 d–V 图上不是一条水平线，而是一组**离散的横带**（d–V 图中的浅蓝条）。这正是 Fig. 6a 中“narrow”类重叠的来源：带宽由腔的精细度决定，必须与工艺容差比较。

实测 EQE（橙点）比 FDTD 理想值（空心点）低 13–24%。这部分不是光学造成的，而是电学损失：IQE × 收集 ≈ 0.87（245 nm）和 0.76（655 nm）。

### 图 (b)：薄器件被 RC 限住，厚器件被渡越限住

两个器件用的是**同一组 μ、V₀、R**：
- **245 nm**：电容大（约 600 pF），f_RC ≈ 950 kHz。在 5 V 下，渡越带宽高达 6 MHz，所以 f₃dB 卡在 RC 上；加偏压几乎不再提速。
- **655 nm**：电容小，f_RC ≈ 2.5 MHz。但渡越时间 ∝ d²/V，在 0.1 V 时只有约 70 kHz，到 5 V 才追到约 820 kHz。

这就是 D10 的边界判定：f_RC ≥ 3f_tr 时降电阻无用；反过来，薄器件再加偏压也无用。

### 图 (c)：暗电流为什么在 300–350 nm 后趋平

5 V 时，薄膜内场强，注入电流随 √F 指数增大。厚度超过约 325 nm 后，注入项降到平台项以下，J_d 就不再随厚度下降。

拟合出的 β 是 Schottky 镜像力理论值的 5 倍。这说明注入不是简单的热电子发射，可能有隧穿或陷阱辅助，所以 N1 在这里只能当经验式用。

0.1 V 下两个厚度的 J_d 差 1.8 倍，模型没有拟合进去（模型假设平台项与厚度无关）。

### 图 (d)：单一 μτ 解释不了两个厚度（与 S4 一致）

如果材料只有一个 μτ，655 nm 器件在 0 V 下的收集比只应有 0.46，实测却是 0.84。反推出的 μτ_eff 随厚度增大 5.6 倍。

这正是 S4（Stolterfoht 2015）的结论：μτ 不是材料常数，只能作为同一器件拟合出的有效参数。所以 d–V 图上我画了两条收集线：实线用 245 nm 的 μτ，虚线用 655 nm 的 μτ。**收集线的位置本身就有约 2.4 倍的厚度不确定度。**

可能的原因（未验证）：
- 共振处的光生分布不均匀，655 nm 器件 m=4 有多个波腹，与 Hecht 的均匀产生假设不符；
- 厚膜的相形貌不同。

### d–V 图：Luong 器件落在哪里

我设的目标是：
- η_A ≥ 0.55（对应 EQE 约 50%）；
- f₃dB ≥ 500 kHz；
- 散粒噪声 D\* ≥ 10¹³ Jones，换算成 J_d ≤ 6.1 nA/cm²（按 EQE = 0.5 计）；
- 收集 η ≥ 0.85。

可行域（青色）只有两段：
- **245 nm 带，约 0.17–1.4 V**：Luong 的 245 nm @0.1 V 器件**不在**模型可行域内——模型在该点给出 f₃dB = 446 kHz < 500 kHz，可行带从 0.17 V 才开始；实测 550 kHz 其实满足目标。另外，目标值（500 kHz、10¹³ Jones）本身是照着原文的宣称值设的，这个点在边界附近不能算独立验证（见第 5 节）；
- **458 nm 带，约 1.15–1.45 V**。

其余三个实测点都在可行域外：
- **655 nm @0.1 V**：带宽只有 60 kHz（渡越限）；
- **655 nm @5 V**：J_d = 38 nA/cm²，超过暗电流目标；
- **245 nm @5 V**：J_d = 456 nA/cm²。

暗电流线在约 1.45 V 处几乎竖直。这是因为平台项随偏压升高，是偏压上限而不是厚度下限。

这个结论**依赖平台项在 0.1 V 与 5 V 之间的插值**：原文只有这两个偏压的数据，中间偏压是对数线性外推，需要 J_d(V) 全曲线来确认。

## 4 局限与需要补的数据

| 局限 | 影响 | 需要补的数据 |
|---|---|---|
| n、k 没有数值，靠反推 | 共振峰宽与峰谷比只能定性对上 | 原文 Fig. 1a 的椭偏数据，或直接用传输矩阵 |
| ε_r 是假设值 | f_RC 与 R_eff 按比例变化，f₃dB 的拟合质量不变 | C–V 或阻抗谱 |
| μτ_eff 随厚度变化 | 收集线有约 2.4 倍的厚度不确定度 | μ_e、μ_h 分别测量；中间厚度（458、720、810 nm）的 R_c |
| 暗电流平台项只有两个偏压点 | d–V 图上暗电流竖线的位置是外推 | 各厚度的 J_d(V) 全曲线（原文 Fig. S8a） |
| 655 nm @0.1 V 在 600–1000 nm 出现谷（原文称为空间电荷收集窄化） | 需要分别知道电子、空穴的 μτ 和可见光 α，才能用 K4 复现 | 分载流子迁移率；600–1000 nm 的 k |

## 5 循环论证审查（样本内 vs 样本外）

脚本：`luong2024_validation.py`，输出 `luong2024_validation.png`。

### 5.1 每个“吻合”用的数据是不是被拟合过

| 之前的表述 | 用于拟合的数据 | 是否循环 |
|---|---|---|
| 共振位置残差 ≤ 5 nm | 245、458、655 nm 本身就是拟合输入 | **是** |
| 共振峰值 61%、78% | 两个峰值拟合 R_f、R_b（2 个点、2 个参数，恰好确定） | **是** |
| 带宽 4 点误差 ≤ 20% | 4 点拟 3 个参数，只剩 1 个自由度 | **基本是** |
| “薄器件受 RC 限制，厚器件受渡越限制” | 这个区分完全由 245 nm @5 V 一个点决定（去掉它后 R 不受约束，预测 5.9 MHz） | **是**，属于由拟合得出的解释，不是检验 |
| 收集比 0.87 / 0.84 | 每个厚度各自反推 μτ，必然完全吻合 | **是** |
| 暗电流 300–350 nm 趋平“与原文一致” | 阈值 325 nm 本身被用来定 β | **是**（上一轮这样表述是错的） |
| 245 nm @0.1 V“落在可行域左端” | 目标值照原文宣称值设定；该点的 f₃dB 被拟合过 | **是**，而且模型其实把它判在域外 |
| 收集线 d_c(V) | μτ 来自同一批器件 | 在这两个厚度上是 |

### 5.2 真正的样本外检验

判定容差（在审查时设定）：
- 比值类量，预测/实测在 1/2–2 倍之间算通过；
- 收集比 R_c 有界于 0–1，用绝对容差 ±0.10。

| 检验 | 预测 | 实测 | 结论 | 说明 |
|---|---|---|---|---|
| 留一法 f₃dB 245 nm @0.1 V | 388 kHz | 550 kHz | 通过（0.71） | |
| 留一法 f₃dB 655 nm @0.1 V | 97 kHz | 60 kHz | 通过（1.61） | |
| 留一法 f₃dB 245 nm @5 V | 5.9 MHz | 900 kHz | **不通过（6.5 倍）** | 去掉后没有数据约束 RC，RC 极限只靠这一个点 |
| 留一法 f₃dB 655 nm @5 V | 126 kHz | 820 kHz | **不通过（0.15）** | 去掉后 μ 与 V₀ 失去约束（V₀ 跑到 5.6 V） |
| J_d 245 nm @0.1 V | 3.0 | 5.5 nA/cm² | 通过（0.54，在容差边缘） | 平台项与厚度无关的假设偏弱 |
| J_d 720 / 810 nm @0.1 V（SI Table S1） | 3.0 / 3.0 | 3.7 / 3.6 | 通过 | |
| J_d 720 / 810 nm @5 V（SI Table S1） | 38.4 / 38.3 | 29.8 / 30.7 | 通过（1.25–1.29） | 实测在 655 nm 后仍继续下降约 25%，“平台”并不平 |
| 共振峰谷比 m=2 / m=4 | 40 / 13 倍 | 约 5 倍（正文实验值） | **不通过** | 有效双镜模型的 Q 太高；实际器件有粗糙度、厚度不均与寄生吸收，使共振展宽 |
| 用 245 nm 的 μτ 预测 655 nm 的 R_c | 0.46 | 0.84 | **不通过** | 单一 μτ 失效，与 S4 一致 |

J_d 的样本外点来自 SI Table S1 的散粒噪声列 i_sh = √(2qI_d)，反推 J_d = i_sh²/(2qA)。用这个方法反推 245、655 nm 的值，与正文报告的 456、38.2、5.5、3.0 nA/cm² 完全一致，说明这一列确实是散粒噪声。

| 原文器件与结果 | 吸收带（η_A ≥ 0.55） | 带宽（≥500 kHz） | 暗电流（≤6.1 nA/cm²） | 判定的独立性 |

| 245 nm @0.1 V | 模型：是 | 模型：**否**（446 kHz）；实测：是（550 kHz） | 模型：是（3.0）；实测：是（5.5） | 吸收与带宽都是样本内；**模型与实测在带宽上判定相反** |
| 245 nm @5 V | 是 | 是 / 是 | 否 / 否 | 样本内 |
| 655 nm @0.1 V | 是 | 否 / 否 | 是 / 是 | 样本内 |
| 655 nm @5 V | 是 | 是 / 是 | 否 / 否 | 样本内 |
| 720、810 nm @0.1 V | — | 无数据 | 是 / 是 | **样本外**，但离边界远（3.0 vs 6.1），区分力弱 |

### 5.4 结论

1. **Luong 2024 的标定只能当作“该器件的参数化描述”，不能当作模型的验证。** 4 个器件点上的区域判定全部是样本内的，“吻合”是拟合的结果。
2. **真正可信的预测能力只有暗电流的厚度外推**（720、810 nm 在 1.3 倍以内），而且这些点离判定边界都远，没有检验到边界本身的位置。
3. **三处明确失败**：
   - 共振峰谷比：有效双镜模型高估 3–8 倍，所以 d–V 图上的吸收横带画得太窄；
   - 单一 μτ：收集线位置不确定约 2.4 倍；
   - 带宽：4 点 3 参数的结构不稳定，RC/渡越的分工依赖单个数据点。
4. **要做成独立检验，需要满足三条**：
   - 标定与检验用不同器件，例如用 245、655 nm 标定，用 458、720、810 nm 的 f₃dB 和 R_c 检验（原文测过这些厚度，但正文只报告了 J_d）；
   - 目标值不能取自被检器件的宣称性能；
   - 吸收改用椭偏 n、k 加传输矩阵计算，不再用峰值反推镜面反射率。

## 6 与 Drive 模型对照后的更正（2026-10-10）

详见 `../与Drive模型对比.md` 第 3 节。

1. **RC 解释不成立**：原文 SI 给出 f_RC = 7.2 MHz，本标定中“245 nm 受 RC 限制（R_eff = 281 Ω，f_RC ≈ 0.95 MHz）”与之冲突。R_eff 只是拟合吸收的自由度。245 nm / −5 V 只有 900 kHz 的原因仍未解决。
2. **μ**：SI 阻抗谱 μ_eff = 2.28×10⁻⁴ cm²/Vs（渡越距离 d/2）。本标定的 1.25×10⁻³（渡越距离 d）换成 d/2 口径是 3.1×10⁻⁴，两者相差 1.4 倍。本标定没有用过 SI 阻抗谱，所以这是一次独立核对。
3. **μτ**：第 2、3 节“单一 μτ 解释不了两个厚度”的结论**降级为未成立**。很可能是在 1100 nm 共振波长（驻波、产生不均匀）上用均匀产生 Hecht 造成的假象。Drive 用单一 μτ = 5.5×10⁻⁹ cm²/V 预测对了 655 nm 在 0.1 V 失效、1 V 恢复；Joseph 2026 同体系独立拟合得 6.0–6.5×10⁻⁹，也支持单一 μτ。本标定 245 nm 的值 3.9×10⁻⁹ 与它们相差约 1.5 倍。
4. **k(1100)**：Drive 从原文 Fig. 1a 数字化得 0.067，本标定反推得 0.041，应以 0.067 为准。
